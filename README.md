# Chiikawa Friends for DAP

치이카와·하치와레·우사기·모몽가를 DAP의 친구로 만나는 비공식 팬 플러그인입니다. 캐릭터 외형과 애니메이션을 적용하고, 원하면 AI 채팅의 이름·성격·말투도 함께 바꿀 수 있습니다.

[최신 버전 다운로드](https://github.com/o-min222/dap-chiikawa-friends/releases/latest) · [모션 교체 현황](MOTIONS.md)

## v2.8.0 · 하치와레 전체 모션 자체화

하치와레의 생각 중·실패·잡힘을 승인된 자체 모션으로 연결했습니다. 네 캐릭터 모두 포함된 자산만으로 전체 시트를 구성하며 외부 원본을 내려받지 않습니다.

## v2.7.0 · 하치와레 자체 모션 확장

하치와레의 대기·좌우 이동·쓰다듬기 반응·새싹 작업·수면·주먹밥 먹기·세수·책상 공부를 승인된 자체 모션으로 연결했습니다. 기존 기타 춤도 유지합니다. 치이카와의 좌우 이동도 포함된 자체 자산으로 전환해 외부 원본 없이 적용됩니다. 하치와레의 생각 중·잡힘·오류 이미지만 기존 원본을 유지합니다.

## v2.6.0 · 이미지형 캐릭터 선택과 모몽가 성격 보강

선택 창을 작고 이동 가능한 형태로 정리했습니다. 드롭다운 대신 기본 이미지와 이름이 있는 네 캐릭터 카드를 제공하고, 선택한 친구의 성격·특징·대표 말투를 바로 옆에서 확인할 수 있습니다. 모션 일시정지 버튼은 제거했습니다. 모몽가는 남의 몫을 탐내고 귀찮은 일은 시키며, 잘되면 자기 공으로 돌리고 실패하면 먼저 남 탓하는 뻔뻔한 성격을 더 분명하게 표현합니다. 정확한 작업 답변과 안전한 상호작용은 유지합니다.

## v2.4.0 · 캐릭터별 호칭과 독립 대화

치이카와·하치와레·우사기·모몽가를 바꾸면 각 캐릭터의 대화 기록과 호칭이 서로 섞이지 않습니다. 별도의 설정 화면은 만들지 않았으며, 캐릭터와 대화 중 “앞으로 나를 민수라고 불러줘”처럼 말하면 그 캐릭터에게만 호칭이 저장됩니다. 직접 정하지 않은 경우에는 각 캐릭터 고유의 부르는 방식이 적용됩니다. 이 기능에는 **DAP 1.6.14 이상이 필요합니다.**

## v2.3.0 · 우사기 클릭 기쁨과 독립 이미지 적용

승인된 우사기 클릭 기쁨을 8프레임·2초로 연결했습니다. 치이카와·모몽가·우사기는 모든 연결 슬롯을 자체 이미지로 구성하며, 오류는 대기, 성공은 각 캐릭터의 자체 반응을 공유합니다. 세 캐릭터는 최초 설치부터 외부 원본 다운로드 없이 적용·미리보기·재시작 복원이 가능합니다. 하치와레의 이미지 준비 여부는 세 캐릭터의 사용을 막지 않습니다.

## v2.2.0 · 모몽가 클릭 기쁨

승인된 8프레임·2초 클릭 기쁨 모션을 연결했습니다. 두 앞발을 들고 눈웃음을 지으며 작게 폴짝인 뒤 기존 대기로 돌아옵니다. 모몽가의 필수 동작은 모두 자체 이미지로 구성하며, 오류 상태는 대기 이미지를 재사용합니다. 모몽가 원본 다운로드는 생략합니다. 전체 모션을 재생하려면 반응 시간 계산을 수정한 **DAP 1.6.11 이상을 권장합니다.**

## v2.1.2 업데이트

DAP 1.6.10에서 네 캐릭터의 클릭 대사를 크림색 바탕·코코아색 윤곽선·둥근 꼬리·작은 볼터치가 있는 만화풍 말풍선으로 표시합니다. 캐릭터별 포인트 색상을 사용하며 일반 답변과 Codex·Claude 작동 배지는 기존 디자인을 유지합니다. 이 디자인은 플러그인과 함께 DAP 본체를 1.6.10 이상으로 업데이트해야 표시됩니다.

## v2.1.1 업데이트

DAP 1.6.9부터 크기 변경 시 스킨 유지, 클릭 전용 캐릭터 대사, Codex·Claude 상태 배지를 기본 지원합니다. 이번 플러그인 버전은 사용 안내와 이전 본체 개발용 통합 패치를 정리한 유지보수 업데이트입니다. 승인된 자체 모션 28개는 그대로 유지합니다.

## v2.1.0 모션 업데이트

- **모몽가 채팅 응답 대기:** 턱을 짚고 갸웃하며 눈을 깜빡이는 8프레임·2.2초 모션으로 교체했습니다.
- **우사기 채팅 응답 대기:** 팔짱을 끼고 “하아?” 하며 갸웃하는 8프레임·2.12초 모션으로 교체했습니다.
- 두 모션은 채팅을 전송한 뒤 AI의 답변을 기다리는 동안 재생합니다. 입력창에 글자를 타이핑하는 동작과는 구분되며, DAP 본체가 춤·수면 상태를 유지하는 경우 기존 우선순위를 따릅니다.
- **캐릭터별 사용자 호칭:** 말투 옵션을 켜면 치이카와는 친구, 하치와레는 친구야·현재 대화에서 알려준 이름, 우사기는 짧은 소리와 사용자를 향한 몸짓, 모몽가는 너·거기 너로 표현합니다. 현재 캐릭터와의 채팅에서 직접 정한 호칭만 우선하며, 온보딩의 공통 호칭이나 다른 캐릭터의 호칭은 이어받지 않습니다.

## v2.0.0에서 달라진 점

- 지원 캐릭터를 **치이카와·하치와레·우사기·모몽가 네 명**으로 정리했습니다. 이전에 다른 캐릭터를 선택했다면 새 캐릭터를 골라 주세요.
- 우사기의 대기·좌우 통통 뛰기·팔 돌리며 일하기·춤·먹기·수면·잡힘·“하아?” 갸웃하기를 승인된 그림체로 통일했습니다.
- 모몽가의 꼬리 춤, 귀여운 척 그루밍, 책·전단지 읽기와 기존 이동·먹기·수면·잡힘 모션을 제공합니다.
- 현재 연결된 동작은 모두 플러그인에 포함된 자체 스트립으로 재생하며 외부 원본을 내려받지 않습니다.
- 실제 DAP에서 사용하는 동작을 기준으로 제작합니다. 독립 점프·기다림은 구형 호환 별칭으로 유지하고, 일반 작업 완료 경로가 없는 성공 슬롯은 기존 캐릭터 반응을 공유합니다. 외부 오류 호환용 실패 슬롯은 하치와레 전용 모션을 사용하며 나머지 세 캐릭터는 각자의 대기 모션을 공유합니다.

## 설치와 사용

**DAP 1.6.14 이상이 필요합니다.** 1.6.14부터 캐릭터별 대화와 호칭을 분리합니다. 1.6.11은 클릭 반응 시간을 클릭 시점부터 계산해 2초 모션이 일찍 끝나는 문제를 수정합니다. 1.6.10부터 캐릭터 클릭 말풍선을 만화풍 디자인으로 표시하고, 1.6.9부터 크기 변경 시 스킨 유지·클릭 전용 대사·Codex·Claude 상태 배지를 기본 지원합니다.

1. [Releases](https://github.com/o-min222/dap-chiikawa-friends/releases/latest)의 ZIP을 DAP 플러그인 설치 기능으로 설치합니다. 카탈로그에 새 버전이 반영되어 있다면 카탈로그에서 설치할 수도 있습니다.
2. **치이카와 친구들**을 엽니다. 치이카와·하치와레·우사기·모몽가 네 캐릭터를 모두 바로 적용할 수 있습니다.
3. 네 캐릭터 중 하나를 고르고 **적용**합니다. 캐릭터 이름·말투·호칭 옵션으로 AI 채팅에도 캐릭터 말투를 적용할 수 있습니다.

네 캐릭터의 연결 모션은 포함된 자체 스트립만 로컬에서 조합합니다. 생각 중·잡힘·외부 오류 호환 슬롯을 포함해 원본 파일을 읽거나 내려받지 않으며, 신규 설치·캐릭터 전환·재시작 복원이 오프라인으로 동작합니다. 이전 설치와의 호환을 위한 원본 검증 코드는 남아 있지만 현재 모션 계획에서 필요한 외부 자산은 없습니다.

치이카와의 좌우 이동은 승인된 8프레임 자체 자산을 플러그인에 포함합니다. 치이카와를 선택할 때 외부 원본을 내려받지 않습니다.

우사기의 클릭 반응까지 자체 모션으로 교체했습니다. 성공 초안, 추가 춤 2, 제거한 거꾸로 숙이기 초안은 이번 배포의 새 재생 동작에 포함하지 않습니다. 치이카와의 기존 성공 그림은 호환 자산으로 보관합니다. 자세한 연결 조건과 교체 현황은 [MOTIONS.md](MOTIONS.md)를 참고하세요.

## 말투와 본체 기능

캐릭터 말투를 켜면 자기 지칭·대화 스타일과 사용자를 부르는 표현도 함께 적용합니다. 별도 호칭을 정하지 않았다면 치이카와는 조심스러운 친구, 하치와레는 친구야·현재 대화에서 알려준 이름, 우사기는 짧은 소리와 사용자를 향한 몸짓, 모몽가는 너·거기 너로 표현합니다. 현재 캐릭터와의 채팅에서 사용자가 직접 정한 이름·호칭만 우선합니다. 온보딩·프로필의 공통 호칭이나 다른 캐릭터에게 정한 호칭은 자동으로 이어받지 않으므로 캐릭터마다 별도의 호칭과 채팅 분위기를 유지할 수 있습니다. 저장된 사용자 정보와 기억 자체는 덮어쓰지 않습니다. 실제 응답은 연결된 AI와 사용자 지침에 따라 달라집니다. [말투 안내](PERSONAS.md)를 참고하세요.

크기 변경 시 스킨 유지, 캐릭터 클릭 전용 말풍선, Codex·Claude 상태 배지는 **DAP 1.6.9부터 포함된 본체 기능**입니다. 대화는 펫 위쪽, 작동 배지는 아래쪽에 표시하며 화면 가장자리에서는 펫을 가리지 않게 위치를 보정합니다. 클릭 대사는 AI 채팅이나 대화 기록에 들어가지 않습니다. 이전 본체 소스를 사용하는 경우에는 [본체 패치 안내](host-patches/README.md)의 통합 패치를 참고하세요. 플러그인만 업데이트하면 이 본체 기능들은 바뀌지 않습니다.

## 개발과 검증

Node 22 이상에서 외부 npm 의존성 없이 빌드합니다.

```sh
npm run verify
npm run dev
```

빌드·테스트에는 네트워크나 이미지 제작 자료가 필요하지 않습니다. `npm run build`는 원본 고정 소스 정보·연결 동작 매핑·승인된 자체 스트립을 플러그인으로 묶습니다. 원본 행과 타이밍 보존, 자체 행 교체, 다운로드 검증, 캐시 재실행, 연결 동작 전체 교체 후 원본 없이 조합하는 경로를 검사합니다.

자체 모션은 한 모션씩 미리보기 확인 후 교체합니다. 로컬 제작 자료가 있을 때 `node scripts/prepare-motion-pack.mjs`로 승인 스트립과 해시 목록을 갱신합니다. `python scripts/package.py`는 코드·원본 소스 메타데이터·검증된 자체 스트립·아이콘만 ZIP에 포함하며 다운로드 원본과 합성 캐시는 제외합니다.

원작 캐릭터의 권리는 나가노 및 각 권리자에게 있습니다. [NOTICE.md](NOTICE.md)를 확인하세요.
