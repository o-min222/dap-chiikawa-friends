# 모몽가 먼저 말걸기와 채팅 동시 표시

현재 개발본의 캐릭터 대사는 아래 **클릭할 때만 캐릭터 말풍선 표시** 방식입니다. 이전 패치들의 자동 발화·채팅 동시 표시는 과거 동작입니다.

플러그인의 모몽가 말투 지침과 별도로 DAP 본체에 적용하는 패치입니다. 기준은 DAP 1.6.5 소스 `46e42a6ee23a080be806c8279f76f41ca93df989`입니다. 개발 체크아웃은 이 프로젝트의 `dist/dap-host-momonga/`에 있으며 설치된 앱과 사용자 채팅 데이터는 수정하지 않았습니다.

- 모몽가의 캐릭터 말투가 활성화된 때만 칭찬 요구·귀여움 자랑·가벼운 질문을 먼저 말걸기 화제로 제공합니다.
- 기존 한가함·작업 중·펫 숨김·방해금지·말걸기 끄기·쿨다운 검사를 그대로 따릅니다. 기본 조용히 설정은 입력 중단 90분 / 발화 후 쿨다운 120분, 균형 설정은 45분 / 60분입니다. 별도 타이머로 빈도를 늘리지 않습니다.
- AI 답변은 한 번만 생성합니다. 기존 대화 기록에 저장된 메시지 id로 열린 채팅창에 즉시 표시하고, 같은 답변을 말풍선에 전달합니다. 사용자가 답하면 그 내용을 대화 이력으로 이어갑니다.
- 다른 캐릭터의 기존 먼저 말걸기 동작과 대사 설정은 유지합니다. 모몽가 전용 화제는 다른 캐릭터나 말투 끄기 상태에서 생성하지 않습니다.

본체 소스 저장소 루트에서 적용합니다. 작업 파일과 충돌하면 강제로 덮어쓰지 말고 해당 변경과 병합하세요.

```powershell
git apply --check 'C:/Users/dudal/OneDrive/문서/ChatGPT/DAP Plugin/host-patches/momonga-companion.patch'
git apply 'C:/Users/dudal/OneDrive/문서/ChatGPT/DAP Plugin/host-patches/momonga-companion.patch'
cd app
pnpm install --frozen-lockfile
pnpm -r build
pnpm --filter @dap/electron-main exec vitest run test/momonga-proactive.test.ts test/proactive-speech.test.ts test/chat-pipeline.integration.test.ts --maxWorkers=1 --minWorkers=1
```

본체 재빌드와 플러그인 개발본 적용 후 사용할 수 있습니다. 플러그인만 업데이트하면 평소 채팅 말투 지침은 반영되지만 본체의 열린 채팅창 동시 표시는 활성화되지 않습니다. 생성 idle과 나머지 13개 모션은 플러그인 1.4.0에 포함됩니다. 모든 독립 동작과 본체 채팅 연동은 DAP 1.6.7부터 지원합니다.

검증: 모몽가 전용 화제와 캐릭터 전환·끄기·작업 중·쿨다운, 같은 메시지의 말풍선/열린 채팅/기록 전달, 사용자 답장의 이력 연결을 실제 DAP 대화 파이프라인에 가짜 LLM을 주입해 검사했습니다. 실제 구독 LLM 호출이나 실행 중인 앱 변경은 하지 않았습니다.

## 독립 모션 확장 (DAP 1.6.7)

`independent-motions.patch`는 본체의 스킨 검증기·capability·렌더러·테스트·API 문서를 확장합니다. 기준 소스는 1.6.6의 `c80f0bf085d08c359174afcffee821ddbf6896b5`이며 기존 API v2와 9개 모션의 대체 규칙을 유지합니다. 수면·먹기·그루밍·잡힘·성공·춤의 동명 클립이 있으면 먼저 사용합니다. 점프는 춤과 독립적입니다.

플러그인 1.4.0은 사용자 PC에서 원본 행을 보존하고 생성 행을 추가합니다. 공개 릴리스에는 합성된 원본 시트를 올리지 않습니다. `supportedMotions`가 없는 구형 본체에는 기존 11행만 등록합니다.

## 읽기 두 버전과 먼저 말걸기 (DAP 1.6.8)

momonga-working.patch는 기존 WorkingMotionPicker가 선택하는 working_v2를 스킨에서도 지원합니다. 책과 전단지를 작업 시작 시 50:50으로 선택하며 작업 중 유지합니다. 모몽가 먼저 말하기는 입력 정지 2분, 발화 후 15분 간격으로 조정하고 꺼짐·방해금지·작업/대화 중·숨김 조건을 유지합니다.

## 크기 변경 시 스킨 유지와 설정 이름 표시

`skin-settings.patch`는 DAP 1.6.8 소스 `11a3feea922ab6bc57a879437f84bd90c1b086cf` 기준 본체 수정입니다. 개발 소스는 `dist/dap-host-motions/`의 `codex/preserve-plugin-skin-on-resize` 브랜치에 있습니다.

- 크기만 바꾸면 플러그인 스킨과 캐릭터 말투를 유지합니다. 기본 고양이·커스텀 미니·미니 프로필을 직접 선택할 때만 플러그인 스킨을 해제합니다.
- 설정의 DAP 모양에 적용된 스킨 이름과 크기를 표시하며, 스킨 전환도 즉시 반영합니다.
- 본체 IPC 처리와 기존 외형 해석기를 사용하며 플러그인 API는 변경하지 않습니다.

본체 저장소 루트에서 `git apply --check <패치 경로>`로 확인한 후 `git apply <패치 경로>`로 적용합니다. `app/`에서 `pnpm -r typecheck`, `pnpm -r build`와 아래 회귀 테스트를 실행할 수 있습니다.

```powershell
pnpm --filter @dap/electron-main exec vitest run test/app.test.ts test/plugin-pet-skins.test.ts test/pet-images.test.ts --maxWorkers=1 --minWorkers=1
pnpm --filter @dap/electron-renderer exec vitest run test/settings-plugin-skin.test.ts test/settings-provider.test.ts --maxWorkers=1 --minWorkers=1
```

검증 결과: 관련 테스트 47개, 전체 타입 검사, 전체 빌드가 통과했습니다. 빌드는 Node 24.19.0에서 검증했습니다. 이 PC의 기본 Node 22.17.1은 기존 번역 파일 복사 단계에서 비정상 종료되어 빌드 명령에만 준비된 Node 24 런타임을 사용했습니다.

이 패치는 소스 수정이며, 설치된 앱에 반영하려면 수정한 본체 빌드로 업데이트해야 합니다. 설치된 앱과 사용자 설정·채팅 데이터는 변경하지 않습니다.

## 캐릭터별 말풍선 전용 대사

`character-bubbles.patch`는 DAP 1.6.8 소스 `11a3feea922ab6bc57a879437f84bd90c1b086cf` 기준 본체 수정입니다. 앞의 `skin-settings.patch`와 별도로 적용할 수 있습니다. 현재 개발 체크아웃에는 두 수정이 모두 적용되어 있습니다.

- 치이카와: “와아…!”, “에헤헤…”처럼 조심스러운 짧은 소리.
- 하치와레: “와아!”, “헤헤, 좋다!”처럼 밝은 반응.
- 우사기: “야하!”, “우럇!”, “푸루루루!” 같은 짧은 소리.
- 모몽가: “이 귀여운 나를 봐!”, “칭찬해 봐!” 같은 귀여움 자랑·칭찬 요구.

선택한 스킨의 대사를 무작위로 골라 기존 말풍선 경로로만 표시합니다. AI 호출, 채팅창 메시지, 대화 기록, 기억 읽기·저장, 다음 답변 문맥에는 전달하지 않습니다. 캐릭터 말투를 꺼도 스킨의 말풍선은 동작하며, 기존 채팅 말투 옵션은 별도로 유지합니다. 일반 고양이의 기존 AI 먼저 말하기는 유지합니다.

최초 `character-bubbles.patch`는 2분 무입력·15분 간격 방식입니다. 이후 사용자 요청에 따른 현재 동작은 아래 `active-character-bubbles.patch`의 작업 중 허용 방식입니다. 말풍선은 기존 방식으로 약 3초 후 사라집니다.

회귀 테스트는 `app/`에서 실행합니다. 네 캐릭터의 대사, 쿨다운·차단 조건·스킨 전환, AI 미호출, 채팅창·기록·다음 사용자 턴으로 전달되지 않는지 검사합니다. 플러그인의 모몽가 채팅 지침에서도 자발적 발화 요구를 제거했습니다.

```powershell
pnpm --filter @dap/electron-main exec vitest run test/momonga-proactive.test.ts test/proactive-speech.test.ts --maxWorkers=1 --minWorkers=1
```

검증 결과: 본체 관련 회귀 테스트 62개와 플러그인 테스트 7개, 전체 본체 타입 검사·빌드, 플러그인 빌드·무결성 검사가 통과했습니다. 본체 빌드는 앞서 확인한 Node 24.19.0 런타임을 사용했습니다. 패치는 기준 소스와 크기 설정 수정본 모두에 적용 가능한지 확인했습니다.

설치된 본체와 플러그인은 자동 교체하지 않았습니다. 새 방식은 본체 업데이트 후 적용됩니다. 기존 사용자 대화 기록은 변경하거나 삭제하지 않습니다.

### 2026-10-18 로컬 설치본 적용 완료

이후 사용자의 명시적 요청으로 설치된 DAP 1.6.8에 크기/스킨 설정 수정과 캐릭터 말풍선 전용 수정을 모두 적용했습니다. 실제 설치본에서 크기 90→110→140→90px 변경 중 모몽가 스킨·말투 유지 및 설정의 `모몽가 · 90px` 표시를 확인했습니다. 원본 앱과 플러그인 백업, 적용 해시, 검증 기록은 `dist/installed-dap-fixes-20261018-194943/`에 있습니다. 검증 후 디버깅 포트를 닫고 설치된 실행 파일을 일반 방식으로 다시 실행했습니다. 공식 배포 버전 번호는 1.6.8로 유지됩니다.

## 작업·입력 중에도 캐릭터 말풍선 표시

`active-character-bubbles.patch`는 위 두 패치가 적용된 소스에 추가하는 수정입니다. 네 캐릭터의 말풍선에만 입력·활동 차단을 해제하며, 일반 고양이의 AI 먼저 말하기는 기존 조건을 유지합니다.

- 키보드·마우스 입력이 계속되거나 펫이 일하기 모션을 재생해도 캐릭터 대사를 허용합니다. 무입력 대기는 필요하지 않습니다.
- 기존 먼저 말하기 설정의 ‘자주’는 최소 5분, ‘가끔’은 최소 15분 간격입니다. 1분 간격 검사로 조건을 확인하므로 앱을 켠 뒤 첫 대사는 보통 1분 이내에 표시됩니다.
- 채팅 답변·생각 중, 오류 상태, 야간 23시~07시, 펫 숨김, 끄기 설정에서는 표시하지 않습니다. AI 호출·채팅 메시지·기록·문맥에는 전달하지 않습니다.

공유 서비스에 선택적인 활동 중 허용 조건을 추가해 기존 야간·끄기·쿨다운·채팅 차단을 재사용했습니다. 타입 검사와 빌드, 코어 및 본체 회귀 테스트 28개가 통과했습니다.

설치된 DAP 1.6.8에도 적용했습니다. 백업과 적용 기록은 `dist/installed-active-bubbles-20261018-200326/`에 있습니다. 설치본의 나머지 개발 변경을 덮어쓰지 않도록 본체 번들의 관련 두 모듈과 설정 화면만 교체했습니다.

## 클릭할 때만 캐릭터 말풍선 표시

이후 사용자 요청으로 네 캐릭터의 자동 대사를 끄고 클릭 응답으로 전환했습니다. `click-character-bubbles.patch`는 앞선 크기·캐릭터 말풍선·작업 중 허용 패치가 적용된 소스에 추가합니다. `click-quick-menu.patch`는 퀵 메뉴가 설정된 경우에도 클릭 반응을 전달하는 화면 수정입니다. 현재 개발 체크아웃에는 모두 반영되어 있습니다.

- 스킨의 캐릭터 대사를 클릭할 때 무작위로 선택해 약 3초 동안 표시합니다. 캐릭터 전환을 즉시 따르며, 말투를 끈 외형만 적용 상태에서도 표시됩니다.
- 네 캐릭터는 자동 발화 타이머에서 제외되며 AI·채팅 메시지·기록·다음 답변 문맥에 들어가지 않습니다. 기본 펫의 기존 자동 말 걸기는 유지합니다.
- 기존 퀵 메뉴도 유지합니다. 드래그·음성 입력 뒤의 클릭은 기존처럼 억제하고, 연속 클릭 말풍선은 한 개씩 교체합니다.

본체·화면 테스트 54개, 본체/화면 빌드와 화면 타입 검사를 통과했습니다. 실제 설치본에서 퀵 메뉴가 설정된 모몽가를 클릭해 `오늘도 귀엽지?` 대사가 3000ms 말풍선과 화면 DOM에 전달되고 채팅 추가는 0건임을 확인했습니다.

설치본 적용 기록과 백업은 `dist/installed-click-bubbles-20261018-202103/`, 퀵 메뉴 클릭 경로 보완 기록은 `dist/installed-click-menu-fix-20261018-202459/`에 있습니다. 관련 모듈과 화면만 교체해 별도 개발 중인 모션 변경은 보존했습니다.
