# Chiikawa Friends for DAP

치이카와·하치와레·우사기·모몽가 네 캐릭터의 외형과 말투를 제공하는 비공식 팬 플러그인입니다. DAP 1.6.1 이상이 필요합니다.

## 자체 모션 전환 개발본

이 버전은 외부 캐릭터 시트나 이미지 저장소에 의존하지 않습니다. 자체 제작한 프레임과 완성된 현대/구형 DAP용 시트를 플러그인에 포함합니다. 설치 후 이미지를 따로 받을 필요가 없고, 플러그인 실행·캐릭터 전환은 오프라인으로 동작합니다.

**모든 동작의 전용 제작이 끝난 버전은 아닙니다.** 기존 승인 모션 17개를 유지하며, 우사기 대기 8프레임 초안 하나를 추가했습니다. 한 모션씩 미리보기 확인 후 다음 모션을 제작합니다. 전용 모션이 없는 동작은 같은 캐릭터의 다른 자체 모션을 임시 사용하며 선택창에 표시합니다. [캐릭터별 제작 현황](MOTIONS.md)을 확인하세요.

- 치이카와: 기존 수면·먹기·그루밍·잡힘·성공·춤 유지. 대기는 그루밍을 임시 사용합니다.
- 하치와레: 기존 기타 춤 유지. 다른 동작은 기타 춤을 임시 사용합니다.
- 우사기: 대기 초안 확인 중. 다른 동작은 이 초안을 임시 사용합니다.
- 모몽가: 대기·좌우 이동·잡힘·먹기·수면·꼬리 춤·귀여운 척 그루밍·책 및 전단지 읽기 유지.

모몽가 읽기 두 버전은 DAP 1.6.8 이상에서 작업 시작 시 기본 선택기로 50:50 선택하고 작업 중 유지합니다. DAP 1.6.7에서는 책 읽기를 사용합니다. 먼저 말하기와 말풍선/채팅 동시 표시는 본체가 담당합니다. 캐릭터 말투와 먼저 말하기를 켜야 하며 방해금지·대화/작업 중·숨김 조건을 따릅니다.

## 사용

DAP의 친구들 메뉴에서 네 캐릭터 중 하나를 고르고 적용합니다. 캐릭터 이름·성격·말투 옵션을 끄면 외형만 적용합니다. 사용자 이름·호칭·기억은 유지됩니다. 제거된 캐릭터의 이전 자동 복원 선택은 해제합니다.

이 2.0.0-alpha.1은 모션을 차례로 검토하는 개발본입니다. 기존 공개 릴리스는 [GitHub Releases](https://github.com/o-min222/dap-chiikawa-friends/releases)에서 확인할 수 있습니다.

## 개발과 검증

Node 22 이상, 외부 npm 의존성 없이 실행합니다.

```sh
npm run verify
npm run dev
```

자체 모션 원본은 한 모션씩 이미지 생성 도구로 제작합니다. 정렬된 스트립을 준비한 뒤 `node scripts/prepare-motion-pack.mjs`로 해시 목록을 갱신합니다. 이 명령은 로컬 제작 자료가 있을 때만 사용합니다. 일반 빌드·테스트에는 제작 자료나 네트워크가 필요하지 않습니다.

`npm run build`는 포함된 스트립만으로 네 캐릭터의 현대/구형 DAP용 시트를 생성합니다. 런타임은 로컬 파일의 SHA-256을 검증하고 읽기만 하며 파일을 다운로드하거나 합성 캐시를 만들지 않습니다. PNG 변조·경로 이탈, 신규 오프라인 설치, 캐릭터 전환·말투·재실행 복원을 검사합니다.

`python scripts/package.py`는 코드·검증된 자체 스트립·조합된 시트·아이콘만 ZIP에 포함합니다. 원작 캐릭터의 권리는 나가노 및 각 권리자에게 있으며, 자세한 설명은 [NOTICE.md](NOTICE.md), 말투 해석은 [PERSONAS.md](PERSONAS.md)를 참고하세요.
