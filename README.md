# Chiikawa Friends for DAP

치이카와·하치와레·우사기·모몽가를 DAP의 친구로 만나는 비공식 팬 플러그인입니다. 캐릭터 외형과 애니메이션을 적용하고, 원하면 AI 채팅의 이름·성격·말투도 함께 바꿀 수 있습니다.

[최신 버전 다운로드](https://github.com/o-min222/dap-chiikawa-friends/releases/latest) · [모션 교체 현황](MOTIONS.md)

## v2.1.0 업데이트

- **모몽가 채팅 응답 대기:** 턱을 짚고 갸웃하며 눈을 깜빡이는 8프레임·2.2초 모션으로 교체했습니다.
- **우사기 채팅 응답 대기:** 팔짱을 끼고 “하아?” 하며 갸웃하는 8프레임·2.12초 모션으로 교체했습니다.
- 두 모션은 채팅을 전송한 뒤 AI의 답변을 기다리는 동안 재생합니다. 입력창에 글자를 타이핑하는 동작과는 구분되며, DAP 본체가 춤·수면 상태를 유지하는 경우 기존 우선순위를 따릅니다.
- **캐릭터별 사용자 호칭:** 말투 옵션을 켜면 치이카와는 친구, 하치와레는 친구야·알려준 이름, 우사기는 짧은 소리와 사용자를 향한 몸짓, 모몽가는 너·거기 너로 표현합니다. 직접 정한 이름·호칭이 있으면 우선합니다.

## v2.0.0에서 달라진 점

- 지원 캐릭터를 **치이카와·하치와레·우사기·모몽가 네 명**으로 정리했습니다. 이전에 다른 캐릭터를 선택했다면 새 캐릭터를 골라 주세요.
- 우사기의 대기·좌우 통통 뛰기·팔 돌리며 일하기·춤·먹기·수면·잡힘·“하아?” 갸웃하기를 승인된 그림체로 통일했습니다.
- 모몽가의 꼬리 춤, 귀여운 척 그루밍, 책·전단지 읽기와 기존 이동·먹기·수면·잡힘 모션을 제공합니다.
- 아직 자체 제작하지 않은 동작은 **기존 패키지의 그림과 타이밍을 유지**합니다. 승인된 모션부터 하나씩 교체하고, 모든 교체가 끝난 뒤 외부 연결을 제거합니다.
- 실제 DAP에서 사용하는 동작을 기준으로 제작합니다. 독립 점프·기다림은 제작 목록에서 제외했고, 일반 작업 완료·오류에 연결되지 않은 성공·실패의 신규 제작은 보류했습니다.

## 설치와 사용

**DAP 1.6.8 이상을 권장합니다.** 1.6.7부터 먹기·수면·그루밍·잡힘·춤을 개별 재생하며, 1.6.8부터 모몽가의 두 읽기 모션을 작업 시작마다 무작위로 선택합니다. 최소 지원 버전인 1.6.1~1.6.6에서는 기존 공용 슬롯에 연결되는 모션만 재생합니다.

1. [Releases](https://github.com/o-min222/dap-chiikawa-friends/releases/latest)의 ZIP을 DAP 플러그인 설치 기능으로 설치합니다. 카탈로그에 새 버전이 반영되어 있다면 카탈로그에서 설치할 수도 있습니다.
2. **치이카와 친구들**을 열고, 처음 한 번 **기존 패키지 이미지 준비**를 누릅니다. 기존 캐시가 있으면 다시 받지 않습니다.
3. 네 캐릭터 중 하나를 고르고 **적용**합니다. 캐릭터 이름·말투·호칭 옵션으로 AI 채팅에도 캐릭터 말투를 적용할 수 있습니다.

이미지는 `heelee912/chiikawa-dots-pets`의 고정 버전에서 사용자 PC로 직접 내려받아 크기와 SHA-256을 확인합니다. 준비가 끝나면 원본과 자체 모션을 로컬에서 조합하며, 이후 캐릭터 전환은 오프라인으로 동작합니다. 다운로드한 원본과 합성 캐시는 배포 ZIP에 포함하지 않습니다.

## 캐릭터별 모션

| 캐릭터 | 적용된 주요 자체 모션 | 아직 교체하지 않은 동작 |
|---|---|---|
| 치이카와 | 먹기·수면·그루밍·잡힘·춤 | 대기·이동·일하기 등은 기존 원본 유지 |
| 하치와레 | 기타를 치며 노래하는 춤 | 다른 동작은 기존 원본 유지 |
| 우사기 | 대기·좌우 이동·일하기·춤·먹기·수면·잡힘·한쪽 갸웃하기·채팅 생각 중 | 클릭 기쁨 반응은 기존 원본 유지 |
| 모몽가 | 대기·좌우 이동·먹기·수면·잡힘·꼬리 춤·귀여운 척·책 및 전단지 읽기·채팅 생각 중 | 클릭 기쁨 반응 등은 기존 원본 유지 |

우사기의 주요 동작은 제작을 마쳤으며 클릭 반응은 선택 보강 대상입니다. 성공 초안, 추가 춤 2, 제거한 거꾸로 숙이기 초안은 이번 배포의 새 재생 동작에 포함하지 않습니다. 치이카와의 기존 성공 그림은 호환 자산으로 보관합니다. 자세한 연결 조건과 교체 현황은 [MOTIONS.md](MOTIONS.md)를 참고하세요.

## 말투와 본체 기능

캐릭터 말투를 켜면 자기 지칭·대화 스타일과 사용자를 부르는 표현도 함께 적용합니다. 별도 호칭을 정하지 않았다면 치이카와는 조심스러운 친구, 하치와레는 친구야·알려준 이름, 우사기는 짧은 소리와 사용자를 향한 몸짓, 모몽가는 너·거기 너로 표현합니다. 사용자가 직접 정한 이름·호칭이 있으면 그것을 우선하며, 저장된 사용자 정보와 기억을 덮어쓰지 않습니다. 실제 응답은 연결된 AI와 사용자 지침에 따라 달라집니다. [말투 안내](PERSONAS.md)를 참고하세요.

크기 변경 시 스킨 유지, 캐릭터 클릭 전용 말풍선, Codex·Claude 상태 배지는 DAP 본체 수정입니다. [본체 패치 안내](host-patches/README.md)의 통합 패치로 세 기능을 함께 적용할 수 있습니다. 대화는 펫 위쪽, 작동 배지는 아래쪽에 표시하며 화면 가장자리에서는 펫을 가리지 않게 위치를 보정합니다. 클릭 대사는 AI 채팅이나 대화 기록에 들어가지 않습니다. 플러그인만 업데이트하면 이 본체 기능들은 바뀌지 않습니다.

## 개발과 검증

Node 22 이상에서 외부 npm 의존성 없이 빌드합니다.

```sh
npm run verify
npm run dev
```

빌드·테스트에는 네트워크나 이미지 제작 자료가 필요하지 않습니다. `npm run build`는 원본 고정 소스 정보·연결 동작 매핑·승인된 자체 스트립을 플러그인으로 묶습니다. 원본 행과 타이밍 보존, 자체 행 교체, 다운로드 검증, 캐시 재실행, 연결 동작 전체 교체 후 원본 없이 조합하는 경로를 검사합니다.

자체 모션은 한 모션씩 미리보기 확인 후 교체합니다. 로컬 제작 자료가 있을 때 `node scripts/prepare-motion-pack.mjs`로 승인 스트립과 해시 목록을 갱신합니다. `python scripts/package.py`는 코드·원본 소스 메타데이터·검증된 자체 스트립·아이콘만 ZIP에 포함하며 다운로드 원본과 합성 캐시는 제외합니다.

원작 캐릭터의 권리는 나가노 및 각 권리자에게 있습니다. [NOTICE.md](NOTICE.md)를 확인하세요.
