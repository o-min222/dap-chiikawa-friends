# Chiikawa Friends for DAP

치이카와·하치와레·우사기·모몽가·시사와 전용 창에서 대화하는 비공식 팬 플러그인입니다. 캐릭터마다 말투와 호칭, 대화 기록을 따로 저장합니다.

## v3.0.0

DAP의 앱 메뉴에서 **친구들과 대화**를 열면 프로필 사진과 이름으로 된 **친구목록** 탭이 나타납니다. 실행할 때 친구들은 대기 상태로 시작합니다. 프로필의 **우클릭·⋯ → 불러오기**로 친구를 부르면 화면에 나타나고 채팅 입력이 활성화됩니다. 프로필을 누르면 **채팅** 탭으로 이동합니다.

프로필이나 채팅창의 **⋯ → 돌려보내기**로 친구를 보내면 화면에서 사라지고 해당 친구의 채팅 입력도 비활성화됩니다. 대화 기록과 크기는 저장되며 다시 불렀을 때 이어집니다. 응답을 기다리다 돌려보낸 경우 늦게 도착한 답변은 대화에 추가하지 않습니다. 채팅창의 **대화 지우기**도 상단 **⋯** 메뉴에 있습니다.

친구목록에서 이름 아래의 **활성·비활성** 표시와 상태 점으로 불러온 친구를 확인할 수 있습니다. 활성 친구는 초록색 점, 비활성 친구는 회색 점으로 표시합니다.

화면에 꺼낸 캐릭터는 잠시 쉬었다 좌우로 걷고 화면 가장자리에서 돌아섭니다. 마우스를 올리거나 대화 중일 때는 멈춥니다. 드래그해 옮기고 클릭하면 그 친구의 채팅창을 엽니다. 여러 친구와 채팅창을 동시에 열 수 있습니다. 우클릭 메뉴에서 **닫기**를 누르면 해당 캐릭터를 화면에서 치웁니다.

채팅창은 DAP 기본 대화창의 시스템 글꼴, 흰 배경, 회색 사용자 말풍선, 입력창과 버튼 크기에 맞췄습니다. 메시지를 입력하고 Enter 또는 보내기를 누르면 답변합니다. Shift+Enter로 줄을 바꿀 수 있습니다.

캐릭터를 우클릭하고 **크기** 슬라이더를 움직여 조절합니다. DAP과 같은 **60~240px 범위, 10px 간격, 기본 130px**입니다. 드래그 중에는 px 표시가 갱신되고 슬라이더를 놓으면 적용·저장합니다. 캐릭터마다 선택한 크기를 재실행 시 복원하며, 이전 % 설정은 비슷한 px 크기로 변환합니다.

친구목록의 프로필 **우클릭·⋯** 메뉴에서도 같은 크기 슬라이더를 사용할 수 있습니다. 화면에 숨긴 친구는 크기만 저장하고, 다시 보일 때 설정한 크기로 나타납니다.

DAP에 연결된 AI 제공자로 대화를 생성합니다. AI 계정과 모델은 DAP의 설정에서 관리합니다. 대기 중에는 생각 중 모션을, 답변이 오면 짧게 기쁨 반응을 보여줍니다.

캐릭터별 최근 120개 메시지를 플러그인 설정에 저장하고, 최근 24개 메시지를 답변 문맥으로 보냅니다. 창을 닫았다 열거나 DAP을 재시작해도 대화가 이어집니다. 답변을 기다리는 동안 다른 친구와 대화할 수 있으며, 각 답변은 해당 캐릭터의 기록에 저장됩니다. **대화 지우기**는 현재 선택한 친구의 기록을 지웁니다.

“앞으로 나를 민수라고 불러줘”처럼 호칭을 직접 정할 수 있습니다. 기본 호칭과 성격 해석은 [PERSONAS.md](PERSONAS.md)에 정리했습니다. 생성되는 말투와 답변은 사용하는 AI 모델에 따라 달라질 수 있습니다.

v2의 스킨 적용 방식에서 전용 채팅 방식으로 전환했습니다. v3의 대화 기록은 새로 시작하며, v2의 DAP 본체 대화는 기존 저장소에 남아 있습니다.

## 설치

DAP 1.6.14 이상이 필요합니다. 플러그인 권한은 전용 창을 여는 `window.palette`입니다. 텍스트 답변은 DAP의 `ctx.host.llm.generate()`를 사용합니다.

DAP 플러그인 목록에서 Chiikawa Friends를 설치하거나 업데이트한 뒤 앱 메뉴에서 친구들과 대화를 여세요.

[최신 릴리즈 다운로드](https://github.com/o-min222/dap-chiikawa-friends/releases/latest)

## 개발

Node.js 22 이상에서 다음 명령으로 빌드와 검증을 진행합니다.

```sh
npm run build
npm test
npm run check
```

`src/plugin.template.mjs`가 채팅·기록·페르소나를 담당하고 `palette/`가 채팅창입니다. `scripts/build.mjs`는 실행 모듈과 채팅 모션 목록을 생성합니다. 캐릭터 정보는 `assets/catalog.json`, 제작 모션은 `assets/motions.json`에서 관리합니다.

이미지는 플러그인에 포함된 자체 제작 PNG를 사용합니다. 채팅창에서 재생하는 모션은 [MOTIONS.md](MOTIONS.md)에 정리했습니다. 캐릭터 권리와 자산 관련 고지는 [NOTICE.md](NOTICE.md)를 참고하세요.
